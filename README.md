# Agent Skills

Reusable agent skill instructions maintained in this repository. The current skill helps create or update a repository README using evidence from that repository.

## Available Skills

| Skill | Description |
| --- | --- |
| [repo-readme](skills/repo-readme/SKILL.md) | Audits repository files and metadata, then creates or standardizes the root `README.md` without inventing unsupported project details. |
